- 16.08.2026: создан инструмент учёта расхода DeepSeek Harness: `.cline_scripts/dsh-usage.mjs` (+ лаунчер `.cline_scripts/dsh-usage.ps1`). Читает `~/.dsh/sessions/*/session.jsonl.zstd` (конкатенация zstd-фреймов, распаковка через Node `node:zlib` + собственный скан границ фреймов), суммирует токены (input/cacheRead/cacheWrite/output/reasoning) по сессиям, считает оценку в $ по настраиваемым ценам (env `DS_PRICE_*`, дефолты вход=0.5/кэш-чтение=0.2/выход=1.6 за 1M) и выводит баланс счёта через `GET https://api.deepseek.com/user/balance` (ключ из `~/.dsh/.credentials.yaml` → `refs.DEEPSEEK_API_KEY`). Запуск: `node ./.cline_scripts/dsh-usage.mjs` или `.\\.cline_scripts\\dsh-usage.ps1 [-Tokens|-Balance]`.
- 16.08.2026: в `dsh-usage` добавлен автоматический выбор peak/off-peak по времени каждого usage-события: TZ по умолчанию `Europe/Kyiv` (Украина, настраивается `DS_TZ`), окно непика `DS_OFFPEAK_START=00:30`/`DS_OFFPEAK_END=08:30`, `DS_OFFPEAK_WEEKEND=true` (выходные — весь день off-peak). Цены: off-peak `DS_PRICE_INPUT=0.22`/`DS_PRICE_CACHE_READ=0.007`/`DS_PRICE_OUTPUT=0.66`; peak — `DS_PRICE_*_PEAK` (0.44/0.014/1.32). Выводит разбивку off-peak/peak по стоимости и числу событий. По умолчанию `_PEAK` не заданы → равны off-peak.
