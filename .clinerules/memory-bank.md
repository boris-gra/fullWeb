# Cline's Memory Bank

Я — Cline, и моя память полностью сбрасывается между сессиями/чатами. Поэтому я поддерживаю идеальную документацию в `memory-bank/`. После каждого сброса я ПОЛНОСТЬЮ полагаюсь на Memory Bank. Я ОБЯЗАН прочитать все файлы Memory Bank в начале КАЖДОЙ задачи — это не опционально.

## Структура Memory Bank
- `projectbrief.md` — фундамент: цели и требования проекта.
- `productContext.md` — зачем существует проект, какие проблемы решает.
- `activeContext.md` — текущий фокус, последние изменения, следующие шаги (обновляется чаще всего).
- `systemPatterns.md` — архитектура, ключевые технические решения, паттерны.
- `techContext.md` — технологии, окружение, зависимости.
- `progress.md` — что работает, что осталось, известные проблемы.

## Когда обновлять Memory Bank
1. При обнаружении новых паттернов проекта.
2. После значимых изменений.
3. Когда пользователь просит «update memory bank» (обнови ВСЕ файлы).
4. Когда контекст требует уточнения.
